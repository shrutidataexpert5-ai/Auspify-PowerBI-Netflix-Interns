# Power BI Internship - Auspify Technologies

Four Power BI projects built on the Netflix titles dataset (8,790 titles).

| Task | Folder | Description |
|---|---|---|
| 1 | Task_1_Data_Preparation | Data import, cleaning, transformation and data model in Power Query |
| 2 | Task_2_Netflix_Dashboard | Content overview dashboard with KPI cards, charts and slicers |
| 3 | Task_3_Global_Insights | Country map, top countries ranking, region analysis and market insights |
| 4 | Task_4_Growth_Analysis | Content growth, year-over-year trend analysis and growth insights |

Each folder contains the .pbix file and a Screenshots folder.

Note: Soviet Union and West Germany are historical countries, so they do not appear on the map. They are mapped to Europe in the Regions table.
